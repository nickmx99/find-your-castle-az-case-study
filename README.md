# Find Your Castle AZ: From idea to live website

A one-page project case study by Nick Castellucci. It documents how I planned, refined, and published a website for my dad's Arizona real-estate business, and what I learned along the way.

This page was created for Handshake Learn's "Create Your First Website and Share It on GitHub" mission.

## What this page includes

- Project overview and goal
- Four process sections: content and navigation, mobile contact experience, publishing and lead integration, and testing and iteration
- Five key lessons
- A contribution disclosure describing how AI tools were used

## AI-assisted workflow

This case-study page was built in [v0](https://v0.app). I provided the requirements, content, and design direction; v0 generated and revised the implementation, and I reviewed the result.

The original Find Your Castle AZ website was also AI-assisted. Planning, requirements, content decisions, review, and iteration were done by me, with AI tools used to help produce and revise the implementation. Original website tools: HTML, CSS, JavaScript, Netlify, Follow Up Boss.

## Scope

This page is intentionally self-contained. It has no forms, CRM connection, authentication, analytics, database, API calls, or credentials, and it does not copy or modify the production business website.
